# Windows 截图功能产品设计与实现方案（修订版）

## 1. 概要与目标

**目标**：基于 WinUI 3 原生桌面能力，构建高质量、低延迟、易用的 Windows 截图工具。  
**核心能力**：
- 全局快捷键触发截图
- 区域 / 全屏 / 窗口捕获
- 同窗口完成注释编辑（矩形、椭圆、箭头、文本、马赛克、高亮）
- PNG/JPEG 导出与复制到剪贴板
- 置顶显示与主程序最小化到任务栏/托盘
- 快捷键、导出格式、质量参数等可配置

**非功能目标**：
- 截图到编辑窗口显示：目标 <200ms（理想）
- 支持多显示器与高 DPI
- 内存占用可控、长时间运行稳定
- 默认本地处理，隐私优先

---

## 2. 技术选型与理由

| 功能域 | 选型 | 理由 |
|---|---|---|
| UI 框架 | WinUI 3 Desktop | 原生体验、现代 UI、支持无边框与 Composition |
| 屏幕捕获 | Desktop Duplication（首选）+ GDI BitBlt（回退） | 性能优先并保障兼容性 |
| 全局热键 | Win32 RegisterHotKey 封装 | 系统级标准能力，稳定可靠 |
| 覆盖窗口渲染 | WinUI + Composition | 高性能渲染，适合交互式编辑 |
| 注释数据 | 矢量对象模型（可序列化） | 支持撤销/重做、二次编辑、会话保存 |
| 导出与剪贴板 | Windows 图像与剪贴板 API | 支持 PNG/JPEG 与跨应用复制 |

---

## 3. 架构设计

- **App 主模块**：启动、退出、托盘、设置、热键生命周期管理
- **Capture Engine**：捕获策略执行与数据返回
- **Overlay Editor**：覆盖编辑窗口与注释交互
- **Export Manager**：导出、复制、会话写入
- **Settings Manager**：配置读写、版本迁移、变更通知
- **内部消息机制**：模块间解耦通信，支持后续扩展插件化

---

## 4. 模块职责与接口契约（文字说明）

### 4.1 热键管理
- 支持注册/反注册热键
- 支持冲突检测与错误提示
- 按键事件统一上报给业务层
- 失败时提供可恢复建议（例如更换组合键）

### 4.2 捕获引擎
- 提供全屏、区域、窗口三类捕获入口
- 返回结果包含：位图数据、DPI 信息、显示器信息
- 首选 Desktop Duplication，失败时自动回退 GDI
- 多显示器场景下保持坐标一致性与 DPI 感知

### 4.3 覆盖编辑器
- 采用“底图层 + 注释层 + UI 层”三层结构
- 注释对象支持选择、拖拽、层级、样式变更
- 支持撤销/重做（命令栈）
- 支持键盘快捷操作（工具切换、保存、复制、取消）

### 4.4 导出管理
- 合成底图与注释图层得到最终结果
- 支持 PNG 无损导出与 JPEG 质量参数导出
- 支持复制到剪贴板（图像主格式 + 兼容格式）

### 4.5 设置管理
- 设置项本地持久化（建议位于用户目录）
- 变更后通知 UI 与功能模块
- 支持配置版本迁移与默认值回填

---

## 5. 关键交互流程

### 5.1 快捷截图并编辑
1. 用户触发全局热键
2. 系统执行捕获或进入区域选择
3. 打开覆盖编辑器并加载底图
4. 用户完成注释编辑
5. 用户执行保存/复制/取消
6. 结果反馈（成功提示、失败重试建议）

### 5.2 区域选择
- 全屏半透明遮罩
- 拖拽创建选区并实时显示尺寸
- 支持移动选区与比例约束
- 确认后进入编辑器

### 5.3 窗口行为
- 编辑器保持置顶，避免被遮挡
- 主程序支持任务栏/托盘最小化
- 编辑器默认不占任务栏入口（可配置）

---

## 6. 数据与会话设计

- 会话数据包含：底图引用、注释集合、DPI、创建时间、版本号
- 支持会话恢复，恢复后可继续编辑与再次导出
- 建议使用版本字段保证未来兼容升级

---

## 7. 性能与稳定性指标

### 目标指标（MVP）
- 截图到编辑窗口可见：P50 < 200ms，P95 < 400ms
- 导出成功率：> 99.5%
- 热键触发成功率：> 99.9%
- 长时运行（8 小时）无内存泄漏级增长
- 4K 单屏与双屏场景均可稳定使用

### 资源管理策略
- 控制内存中的历史位图缓存数量
- 大图显示使用缩放显示，导出使用原始分辨率
- 捕获会话及时释放 GPU/句柄资源
- 导出与 IO 异步执行，避免 UI 卡顿

---

## 8. 可配置项建议（MVP）

- 截图快捷键（支持冲突检测）
- 默认捕获模式（区域 / 全屏 / 窗口）
- 默认导出格式（PNG / JPEG）与 JPEG 质量
- 编辑器是否显示任务栏入口
- 保存目录与文件命名规则
- 是否启用性能降级提示

---

## 9. 异常处理与降级策略

- **Desktop Duplication 不可用**：自动切换 GDI，并提示“性能降级模式”
- **热键冲突**：提示冲突来源并引导重新绑定
- **剪贴板写入失败**：保留临时导出文件并提示路径
- **文件写入失败**：提示权限/路径问题并提供重试入口
- **多屏切换异常**：回退到主屏截图并上报诊断信息
