# EasySnipping 隐私政策（草稿）

生效日期：2026 年 8 月 12 日

本隐私政策适用于 EasySnipping Windows 应用。发布到 Microsoft Store 前，请将本文件放置在应用提供方控制的公开 HTTPS 网站，并将实际网页地址填写到 Partner Center。本文是发布资料草稿，不替代针对实际运营主体的法律审核。

## 我们处理哪些信息

EasySnipping 不要求用户创建账号，也不在应用内提供广告、社交功能或云端账户服务。

- 屏幕截图内容：只有在用户主动开始截图时，应用才捕获屏幕内容。
- 标注和 OCR 文本：默认在本机内存中处理。Windows OCR 由设备上的 Windows 能力提供，是否可用取决于系统和语言包。
- 导出文件：用户主动保存时，按照用户选择的目录写入 PNG 或 JPEG 文件。
- 剪贴板内容：用户主动复制截图或 OCR 结果时，写入 Windows 剪贴板。
- 设置：应用在本机保存快捷键、保存目录、主题、语言、OCR 选项和其他偏好设置。

## 我们不会做什么

在当前版本中，EasySnipping 不会主动向应用提供方上传、出售或共享屏幕截图、OCR 文本、标注内容或应用设置；不使用广告追踪器，也不要求网络连接来完成基本截图、标注、保存和复制操作。

如果用户使用 Windows 或其他应用提供的同步、备份、分享或剪贴板管理功能，这些功能由相应服务提供方按照其自己的隐私政策处理。

## 数据保留和删除

导出的截图、剪贴板内容和本机设置由用户控制。用户可以删除导出文件、清理剪贴板或删除应用设置。卸载应用不会自动删除用户主动导出的截图文件；如需删除，请从保存目录中手动删除。

## 第三方组件

应用使用 Windows 和 Windows App SDK 提供的系统组件，包括 Windows OCR 相关能力。系统组件可能受 Microsoft 的条款和隐私政策约束。
