### 详细描述

EasySnipping 是一款轻量的 Windows 截图工具，帮助你快速捕获屏幕内容、标注重点并立即使用。

主要功能：

- 使用全局快捷键 `Ctrl+Shift+S`、托盘菜单或托盘图标启动截图。
- 支持多显示器和虚拟屏幕坐标。
- 自动检测窗口和控件；也可以直接拖拽创建自由选区。
- 选区确认后可以移动选区，或调整八个方向的边界。
- 使用矩形、椭圆、箭头、直线、文字、高亮、马赛克和画笔进行标注。
- 调节形状透明度、边框/填充、箭头方向、实线/虚线、文字字号和文字样式。
- 使用 Windows OCR 识别选区中的文字，并复制识别结果。
- 将结果保存为 PNG 或 JPEG、复制到剪贴板，或作为置顶贴图使用。
- 设置保存目录、主题、界面语言、OCR 引擎和开机自启。

EasySnipping 不要求账号。截图、标注和 OCR 文本默认在本机处理；只有在你主动保存、复制或置顶时，内容才会写入对应的本地目标。OCR 功能是否可用取决于 Windows 的语言包和系统能力。

### 此版本新增内容

本版本改进智能截图选择体验：自动检测状态下鼠标保持十字光标，减少自动检测与自由拖拽截图之间的视觉差异。同时包含 OCR 后端选择和增强标注样式等改进。
