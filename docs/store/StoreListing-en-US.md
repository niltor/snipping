### Full description

EasySnipping is a lightweight Windows screenshot tool for quickly capturing screen content, highlighting important details, and using the result right away.

Key features:

- Start a capture with the global `Ctrl+Shift+S` shortcut, the tray menu, or the tray icon.
- Capture across multiple monitors and the virtual desktop coordinate space.
- Automatically detect windows and controls, or drag to create a free-form selection.
- Move a confirmed selection or resize it from any of its eight handles.
- Annotate with rectangles, ellipses, arrows, lines, text, highlights, mosaics, and freehand drawing.
- Adjust shape opacity, border/fill, arrow direction, solid/dashed lines, text size, and text style.
- Use Windows OCR to recognize text in the selection and copy the result.
- Save as PNG or JPEG, copy to the clipboard, or keep the result as an always-on-top image.
- Configure the save directory, theme, interface language, OCR backend, and startup behavior.

EasySnipping does not require an account. Screenshots, annotations, and OCR text are processed locally by default; content is written to a local destination only when you choose to save, copy, or pin it. OCR availability depends on the Windows language packs and capabilities installed on the device.
