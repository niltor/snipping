# EasySnipping Privacy Policy (Draft)

Effective date: August 12, 2026

This privacy policy applies to the EasySnipping Windows application. Before submitting to the Microsoft Store, host this document at a public HTTPS URL controlled by the application provider and enter the actual webpage URL in Partner Center. This is a publishing draft and does not replace legal review for the operating entity.

## Information processed

EasySnipping does not require an account and does not provide advertising, social features, or a cloud account service inside the app.

- Screen content: the app captures screen content only when the user actively starts a capture.
- Annotations and OCR text: processed in local memory by default. Windows OCR is provided by capabilities on the device, and availability depends on the Windows system and installed language packs.
- Exported files: when the user chooses Save, the app writes a PNG or JPEG file to the directory selected by the user.
- Clipboard content: when the user chooses to copy a screenshot or OCR result, the content is written to the Windows clipboard.
- Settings: the app stores shortcut, save-directory, theme, language, OCR, and other preference settings locally.

## What we do not do

In the current version, EasySnipping does not proactively upload, sell, or share screenshots, OCR text, annotations, or app settings with the application provider. It does not use advertising trackers and does not require a network connection for basic capture, annotation, saving, or copying.

If the user uses Windows or another app's sync, backup, sharing, or clipboard-management features, those features are handled by their respective providers under their own privacy policies.

## Retention and deletion

Exported screenshots, clipboard content, and local settings are controlled by the user. The user can delete exported files, clear the clipboard, or remove app settings. Uninstalling the app does not automatically delete screenshots that the user exported; delete those files manually from the save directory if desired.

## Third-party components

The app uses Windows and Windows App SDK system components, including Windows OCR capabilities. Those system components may be subject to Microsoft's terms and privacy policy.
