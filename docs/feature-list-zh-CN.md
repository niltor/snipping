# 功能清单（当前实现）

本文以仓库当前源码为准。标为“规划”的内容不代表当前版本已经提供。

## 1. 正式入口与运行链路

正式入口是 `src/Snipping.App/Program.cs`：

1. 以 STA 模式启动，并通过 `Local\\Snipping.Capture.SingleInstance` 保证单实例。
2. 设置 `PerMonitorV2` 高 DPI 模式，初始化 WinForms，运行 `SnippingApplicationContext`。
3. 应用上下文加载 `%LocalAppData%\\Snipping\\settings.ini`，创建托盘图标，并注册全局热键。
4. 托盘双击、托盘菜单“立即截图”或注册成功的全局热键都会进入 `StartCapture()`。
5. `StartCapture()` 在显示覆盖层前准备屏幕底图，再打开 `DesktopSnippingOverlayForm`；捕获、选区、标注、OCR、保存、复制和置顶均在该覆盖窗体中完成。

当前正式热键默认是 `Ctrl+Shift+S`。设置窗口可修改热键、置顶快捷键、保存目录、主题、语言、OCR 偏好语言和开机自启。

正式覆盖流程创建覆盖整个虚拟屏幕的 `Format32bppArgb` 位图，并在覆盖层显示前调用 GDI+ `Graphics.CopyFromScreen` 同步复制屏幕；`OnShown` 只在底图尚未准备时兜底捕获。当前正式路径没有接入 Desktop Duplication。

`Form1` 仍包含另一套 WinForms/GDI 捕获代码，但 `Program` 当前不会实例化它；它不是本清单所称的正式入口。

## 2. 截图与标注功能

### 截图

- 覆盖整个虚拟屏幕，支持多显示器坐标范围。
- 鼠标拖拽创建自由选区，最小有效尺寸为 2×2 像素。
- 支持智能选区：截图会话开始时建立可见顶层窗口和子 HWND 矩形快照，鼠标移动时先做本地命中；对宿主窗口再按根窗口缓存 UI Automation 快照，最后使用局部视觉候选，失败时回退到窗口边界；也可继续自由拖拽。
- 选区确认后可移动、调整八个方向的边界手柄，点击外部可重新选区。
- 选区确认后的工具栏优先显示在选区下方；下方空间不足时自动翻到上方；上下都不足时放入选区内部，并进行屏幕边界修正。
- `Esc` 或鼠标右键取消当前截图。
- 当前正式入口始终先进入覆盖选区流程；设置对象中的 `DefaultCaptureMode` 虽然默认是 `Region`，但尚未由 `SnippingApplicationContext` 分派全屏或窗口模式。

### 标注

覆盖编辑器提供以下工具：

- 矩形、椭圆、箭头、直线；
- 文字：可输入、编辑、拖动和调整文本框大小，`Ctrl+滚轮` 调整字号（10–100 像素）；
- 高亮、矩形马赛克、画笔马赛克、自由画笔；
- 颜色：红、蓝、绿、黄、白；
- 撤销最近一次标注；当前没有重做栈。

默认工具是矩形，工具快捷键为 `Q/W/E/R/T/A/S/D`（依次对应矩形、椭圆、箭头、直线、文字、高亮、马赛克、画笔）。

当前版本已加入按工具保存于当前截图会话的增强选项模型（不写入 `settings.ini`）：

| 工具 | 选项及默认值 |
|---|---|
| 矩形、椭圆 | 透明度 `100`（范围 10–100），模式“边框” |
| 箭头 | 单箭头；可选双箭头 |
| 直线 | 实线；可选虚线 |
| 文字 | 字号 `18`（范围 10–100），粗体关闭，斜体关闭 |
| 马赛克 | 画笔范围 `20`（范围 5–50） |

这些选项由覆盖编辑器下方的紧凑第二行工具栏承载；工具名称不再占用空间，模式切换使用图标按钮，悬停显示本地化提示，滑块项按内容自适应宽度。选项适用于之后新建的标注；高亮和自由画笔当前没有对应的增强选项。

### 输出与增强操作

- 保存为 PNG 或 JPEG；可在设置中选择默认格式。PNG 使用无损压缩并优化文件体积，JPEG 质量可调（默认 90），适合优先减小文件大小的场景。
- 复制选区（含标注）到剪贴板。
- 置顶贴图：默认快捷键 `Ctrl+T`，默认不透明度 90%。
- Windows OCR：对当前选区异步识别，在 OCR 面板显示文本和行框；依赖可用的 Windows OCR 语言包。
- 保存默认目录为“图片\\Snipping”，默认文件名前缀为 `snip`。

## 4. 内部能力开关与状态

- `FeatureEntitlements.AnnotationEnhancementsEnabled` 是运行时能力开关，默认 `true`，不持久化；后续可由授权层替换为唯一能力来源。它控制增强选项面板是否显示。
- 智能选区没有单独的用户开关；覆盖窗体处于选择阶段时自动进行 UI Automation 探测。
- OCR 由工具栏按钮或 `Ctrl+A` 触发；运行期间使用取消令牌，选区变化或关闭窗口会取消识别。
- 覆盖窗体内部以 `Selecting`、`Ready`、`Drawing` 三个阶段管理交互；`_ocrMode`、`_ocrRunning` 和候选选区属于运行时状态，不是持久化配置。
- `ShowPerformanceDegradeTip` 是现有配置字段，但当前源码没有对应的提示消费点；不能据此宣称已经支持捕获引擎降级提示。
- 设置页“高级”标签已预留 Microsoft Store 付费版功能位置，当前显示为未开放，不对应已启用的付费能力开关。
- Desktop Duplication 是后续捕获引擎规划，不是当前内部开关或可选后端。

## 5. 性能指标

### 当前实现特征

- 首帧屏幕复制在覆盖层显示前同步执行，使用 GDI+ `CopyFromScreen`，避免把覆盖层自身截入底图。
- 智能选区按 6px 网格去重，使用 30ms 静默期、90ms 最大等待和单一专用后台 worker，只保留最新请求。
- 覆盖层显示前先执行一次 `EnumWindows`/`EnumChildWindows`，缓存窗口、子控件矩形、可见性、类名和枚举顺序；鼠标热路径不再调用 `EnumWindows` 或 UI Automation。
- 面积超过根窗口 55% 的 HWND 宿主只作为临时候选，鼠标停留约 55ms 后才进入精确阶段；原生叶子候选直接返回，不额外查询。
- 精确阶段按根窗口缓存 UI Automation Raw View 属性（最多 2048 个元素、约 120ms 预算），后续鼠标移动只在该快照中命中；快照有效期约 2 秒。
- UIA 仍只有容器时，在当前 HWND 容器内执行多扫描线、连续边缘支持度和面积比例分析，生成低优先级视觉候选；置信度不足时保留容器/窗口候选，不把随机边缘当作精确控件。
- 候选带来源和置信度，原生控件、UIA、视觉区域、窗口回退按可靠性处理；已命中的叶子不会被较大容器或整窗回退覆盖。
- 候选变化只使旧/新候选矩形并集失效，并且覆盖层只重绘无效矩形；过期异步结果按鼠标位置丢弃，异常时保留自由拖拽能力。
- OCR 与文件导出使用异步任务；仓库没有记录运行时延迟、内存或成功率实测数据。

### 目标与验收口径

以下沿用产品设计目标，不是当前版本实测结果：

| 指标 | 目标 |
|---|---:|
| 截图到编辑窗口可见 | P50 < 200ms，P95 < 400ms |
| 导出成功率 | > 99.5% |
| 全局热键触发成功率 | > 99.9% |
| 长时间运行 | 8 小时无内存泄漏级增长 |
| 分辨率场景 | 4K 单屏、双屏稳定 |

性能验收应额外记录捕获耗时、智能选区候选耗时/P95、OCR 耗时、导出耗时、取消任务数和内存峰值；当前没有自动化基准矩阵。

## 6. 测试矩阵

测试项目包括 `tests/Snipping.Core.Tests` 和 Windows 目标的 `tests/Snipping.App.Tests`，当前共 30 个 xUnit `[Fact]`：

| 范围 | 测试内容 | 当前覆盖 |
|---|---|---:|
| `CaptureResult` | 图像数据、格式、DPI、显示器标识赋值 | 1 |
| `ExportManager` | 导出扩展名、文件存在性、字节内容、时间命名 | 1 |
| OCR 几何 | 单词合并边界、阅读顺序、无效行过滤 | 2 |
| OCR 结果 | 空成功、错误、带提示的成功状态 | 1 |
| `SettingsManager` | 缺省值、保存/加载、非法值迁移 | 3 |
| 标注渲染/样式 | 矩形透明度、边框/填充、双箭头、虚线、文字样式、马赛克底图保护、能力/状态、选项栏图标/宽度 | 10 |
| 智能选区与版本 | 请求合并、单查询并发、快照缓存窗口过期刷新、临时候选精细化、候选优先级、关于页四段版本号、诊断指标 | 7 |
| 工具栏布局 | 下方、上方、选区内部回退及屏幕边界修正 | 5 |
| WinForms/UI | 入口、热键、覆盖窗体、标注、剪贴板、贴图 | 未覆盖 |
| 捕获性能 | GDI/未来 Desktop Duplication 延迟与资源 | 未覆盖 |
| 多显示器与 DPI | 实机捕获及坐标一致性 | 未覆盖 |

因此，单元测试通过不能替代 Windows UI 手工验收，也不能证明当前性能目标已经达成。
